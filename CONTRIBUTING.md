# Contributing to SII

We welcome community contributions to the `SII` package!

## Reporting Issues
If you encounter a bug, have a feature request, or need support, please open an issue on the [GitHub Issues](https://github.com/euphonic-euphemism/SII/issues) page. Please include reproducible R code examples using the `reprex` package if reporting a bug, along with your `sessionInfo()`.

## Contributing Code
To contribute code:
1. Fork the repository and create a feature branch.
2. Submit a Pull Request with a clear description of the changes.
3. Ensure that all `testthat` unit tests pass.
4. Keep your code style consistent with standard R guidelines (e.g., tidyverse style guide).
5. If adding a new feature, please include corresponding tests in the `tests/testthat/` directory.
