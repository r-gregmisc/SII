# Namespace Revivification Agreement

The core ANSI engine of this `SII` package was originally developed by Gregory R. Warnes and released on CRAN under the GPL license. 

Following the archival of the original `sii` package (version 1.0) on CRAN, maintainership formally transferred to Mark Shaver starting with version 1.1.0, with documented agreement to revive the namespace and continue development under the GPL-3.0 license.

All subsequent modeling (`calculate_loudness`), the S3 API refactoring, the WebAssembly implementation, and the `Open-NL` prescriptive logic were independently developed by Mark Shaver.
